# XXD Panel 094 オリジナルプロンプト · 日本語閲覧訳

アップロードした各写真を、個別の高品質デザインポスターにします。複数画像は結合せず、3:4縦構図、上半分と下半分を高さ1:1（各50%）で構成します。上半分は元写真の主体、構造、姿勢、質感、自然光、色の雰囲気を保ち、軽い写真調整だけを行います。

下半分は写真から最も識別できる主体・輪郭・姿勢・物語上の関係を抽出し、**Pen-and-ink line illustration with spot color** の古書挿絵として再構成します。細い抑制された墨線、局所的な黒ベタ、少量のハッチングで形を示し、背景は消して初期書籍挿絵の簡潔で詩的な状態にします。

色は黒インクと写真から選んだ一色の特色だけ。特色は少数の要所に使い、全面を写実的に着色しません。黒白、紙色、特色による明確な二色印刷のリズムを保ちます。**extreme negative space** を重視し、主体を小さく、孤立させ、偏らせ、または空白に浮かせます。手仕事の揺らぎを持つ細い装飾枠や隅飾りを加えても構いません。

背景は穏やかな古紙色、象牙色、微暖色の紙。軽い紙繊維、印刷むら、墨線の途切れ、見当ずれは残しますが、汚い古び加工にはしません。文字は少量で、固定題名・番号・場所・言語を設定せず、主体・感情・動作・記憶・文化的文脈から短い語や詩的断片を生成します。細く端正で古い活字の不均一さを持つ古典出版書体を、ページに最初から刷られたように配置します。

全体は細墨線、局所黒、単一特色、極大余白、手描き枠、古書組版による上質な復古感。20世紀初頭の児童書、詩集、古典編集挿絵、二色刷りを参照し、全面着色、複雑背景、現代漫画、水彩風景、輪郭フィルター、太い漫画線、デジタルグラデーション、3D、過剰な汚し、商業テンプレートを避けます。
