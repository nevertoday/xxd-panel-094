# XXD Panel 094 オリジナルプロンプト · 日本語閲覧訳

アップロードした各写真を、それぞれ独立した上質なデザインポスターにしてください。複数画像を結合せず、写真ごとに個別出力します。全体は3:4の縦構図とし、上下二つの領域の高さを厳密に1:1、各50%にします。

上半分には元写真を残し、主体の同一性、構造、姿勢、実在する質感、自然な光と影、元の色彩の空気を保ちます。調整は軽い上質なカラーグレーディングだけにとどめ、アート雑誌、独立出版物、展覧会写真のような質感にします。画幅に合わせて周囲の環境を自然に拡張しても構いませんが、主体を引き伸ばしたり、歪めたり、変更したりしてはいけません。

下半分では、写真の中で最も識別しやすい**主体、輪郭、姿勢、物語上の関係**を抽出し、**Pen-and-ink line illustration with spot color** スタイルのヴィンテージ書籍挿絵として再構成します。写真全体をそのまま描写せず、主体の同一性と感情を保つために必要な情報だけを残します。細く抑制された墨線、局所的な黒ベタ、少量のハッチングで形をつくり、複雑な背景は積極的に消します。人物、動物、建築、植物、器物、風景のいずれも、初期の書籍挿絵のように簡潔で、物語性があり、詩的な状態にします。

色彩は**黒インク＋単一の特色**だけに限定します。上の写真から最も識別性が高く、生命力があり、または象徴的な一色を抽出し、適度に純化します。その色は衣服、建築の一部、植物、光、器物、物語の焦点など、少数の重要箇所だけに使い、現実の光に沿って全面を着色しません。明確な **two-color printing aesthetic / limited-color print illustration** を保ち、黒と白、紙の色、一つの特色の関係によって視覚的なリズムをつくります。

構図では **extreme negative space** を強調します。主体を小さくしたり、孤立させたり、片側に寄せたり、広い空白の中に浮かせたりして構いません。画面を埋めるのではなく、スケールの対比、位置、方向、ごく少数の環境的手掛かりによって感情をつくります。元写真の気配に応じて、手仕事のわずかな誤差を残す細い装飾枠を加えるか、枠の一部、隅飾り、細い罫線だけを残しても構いません。商業ポスターのテンプレートではなく、古い児童書、詩集の口絵、古典的出版物の独立挿絵のように見せます。

背景には穏やかな古紙色、象牙色、またはわずかに暖かい紙色を使います。軽い紙繊維、印刷むら、途切れる墨線、見当ずれを残しても構いませんが、汚いヴィンテージフィルターにはしません。年代感を持ちながらも、清潔で、洗練され、呼吸できる画面にします。

文字は少量だけ介入させ、固定の題名、番号、場所、言語をあらかじめ設定しません。写真の主体、感情、動作、記憶、文化的文脈から、少数の語、短い文、詩的断片を自由に生成します。書体は**細く端正で、古い活字の不均一さと書籍印刷の誤差をわずかに持つ古典的出版書体**とします。枠、主体、大きな余白との関係から、見出し、傍注、題記、小さな口絵のように組んでも構いません。文字は後から見出しを貼り付けたようにせず、最初から書頁に印刷されていたように見せます。

全体は、**細い墨線、局所的な黒ベタ、単一の特色、極大の負の空間、手描きの装飾枠、古書的な組版**が一体となった上質なヴィンテージ表現にします。20世紀初頭の児童書挿絵、詩集挿絵、古典的な編集挿絵、二色刷り出版物を参照します。全面着色、複雑な背景、現代的なカートゥーン、水彩風景、写真の輪郭抽出フィルター、太い漫画線、デジタルグラデーション、3Dレンダリング、過剰な古び加工、商業テンプレート感は避けます。
